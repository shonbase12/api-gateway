### Error Response Structure
- **error_code**: A unique code representing the error type.
- **error_message**: A human-readable message providing details about the error.
- **timestamp**: The time when the error occurred.

### Example Response
```json
{
  "error_code": "INVALID_REQUEST",
  "error_message": "The request parameters are invalid.",
  "timestamp": "2026-05-17T07:11:16Z"
}
```
